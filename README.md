## Status

**Sprint 0 — kickoff via Design Thinking**. Sem código de produção ainda. Foco: brief, IA, design tokens, protótipos HTML+CSS, backlog QSCRUM.

## Como o projeto está organizado

- [`.design/research/`](.design/research/) — Fase 1 (Empatizar): empathy map, personas, JTBD, análise competitiva.
- [`.design/pokedex/`](.design/pokedex/) — Fases 2-5: brief, IA, tokens, tasks, review, user test, notas de portabilidade HTML→QML.
- [`prototypes/`](prototypes/) — Fase 4: HTML+CSS puro, descartável (referência visual para QML).

- `src/`, `tests/`, `CMakeLists.txt` — **ainda não criados**. Entram na Sprint 1.
